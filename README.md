# Digital Services

A mobile-friendly digital services dashboard for managing
social media campaigns, account access, and analytics.

## Project Features

- Responsive landing page
- Signup interface
- Email verification workflow
- Email and password login
- Password recovery interface
- User dashboard
- Instagram, Facebook, and YouTube service sections
- Supabase authentication integration
- Expandable service and order management architecture

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Supabase Authentication
- Supabase PostgreSQL Database
- Render hosting

## Project Structure

```text
Digital-Services/
├── index.html

├── README.md
└── render.yaml
```

Additional configuration files will be added as the project grows.

## Development Status

The frontend files provide the initial user interface.

Authentication requires valid Supabase project configuration.
Order management, wallet transactions, admin tools, and
provider integrations must be implemented separately.

## Security

- Never publish secret API keys.
- Keep service-role keys on a trusted server only.
- Apply database access policies before storing user data.
- Validate transactions on the server.
- Do not trust client-submitted wallet balances.
- Use authorized integrations and follow platform policies.
